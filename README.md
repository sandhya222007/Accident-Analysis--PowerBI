 Accident Analysis using Power BI

 📌 Project Overview

This project analysis accident data using Microsoft Power BI to identify
accident trends, patterns, severity, and key insights.

The project includes data cleaning, exploratory data analysis, and
interactive dashboard creation.

 🎯 Objectives

- Analysis accident trends and patterns
- Understand accident severity
- Identify important accident factors
- Perform data cleaning and preprocessing
- Create an interactive Power BI dashboard
- Generate meaningful insights from accident data

🛠️ Tools & Technologies

- **Power BI** – Dashboard and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculations and measures
- **Python** – Data analysis
- **Jupyter Notebook** – Exploratory data analysis
- **Microsoft Excel** – Data preparation
- **CSV** – Dataset
 📂 Project Files

- `powerBI.pbix` – Power BI dashboard
- `AccidentInsight_500_Rows.csv` – Accident dataset
- `AccidentInsight_Cleaned.xlsx` – Cleaned accident dataset
- `accident analysis.ipynb` – Python analysis notebook
- `README.md` – Project documentation

 📊 Dashboard

An interactive Power BI dashboard was created to analyze accident
patterns, trends, severity, and other important accident-related insights.

The dashboard contains interactive visualizations, charts, KPIs,
and filters for better data analysis.

🔍 Key Analysis

- Accident severity analysis
- Accident trend analysis
- Accident pattern analysis
- Data cleaning and preprocessing
- Exploratory data analysis
- Interactive Power BI visualizations
- Data-driven insights

 🔄 Project Workflow

1. Collected the accident dataset
2. Cleaned and prepared the data
3. Performed exploratory data analysis using Python
4. Transformed the data using Power Query
5. Created DAX calculations and measures
6. Built an interactive Power BI dashboard
7. Analyzed accident trends and patterns
8. Derived meaningful insights from the data

 📈 Project Outcome

The project provides an interactive dashboard that helps users
understand accident patterns, severity, and trends through
data visualization and analysis.
